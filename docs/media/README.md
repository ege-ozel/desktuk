# README illustrations

The SVGs are original static diagrams, not application screenshots. Example filenames
contain no user data. They use the DeskTuk theme and plain vector paths/text, without
scripts, external fonts, raster dependencies or application runtime cost.

- desktop-overview.svg: circles and panel interaction overview.
- search-order.svg: prefix-before-substring ranking and the default selection.

The brand card in ../../res/brand/card.png is the existing approved identity asset.
The illustrations simplify geometry and icons; native Windows icons vary by file.
