# DeskTuk kullanım kılavuzu / Quick guide

[Türkçe](#türkçe) · [English](#english)

## Türkçe

### 1. Çemberleri kullanın

Çemberin üzerine gelerek içeriğini görün. Dosya simgesine tıklayarak açın. Çemberler dosyaların yollarını saklar; gerçek dosyaları taşımaz. Explorer'dan bir çembere dosya veya kısayol bırakabilirsiniz.

### 2. Düzenleyin ve taşıyın

Sağ tık menüsünden çember veya grup oluşturun, adlandırın ve düzenleyin. Bir dosyayı başka çembere sürüklemek yalnızca DeskTuk içindeki başvurusunu değiştirir. Dosyaya sağ tıklamak Windows'un kendi menüsünü açar; orada seçtiğiniz dosya işlemleri gerçek dosyaya uygulanır.

### 3. Çemberde arayın

Açık çember üzerinde yazmaya başlayın; tek harf yeterlidir. Önce adı sorguyla başlayanlar, ardından sorguyu içinde bulunduranlar görünür. Her iki eşleşme grubunda mevcut sıra korunur. İlk öğe, yazmadan önce de vurguludur. Yukarı/aşağı oklar seçimi değiştirir; Enter vurgulananı açar. Fareyle bir dosyaya gelmek hover vurgusuna öncelik verir.

### 4. Arama metnini düzenleyin

Yazmaya başlayınca gerçek bir metin kutusu açılır. Ctrl+A, Ctrl+C/X/V/Z, Shift+oklar, Home/End ve fareyle metin seçimi kullanılabilir. Backspace siler; Esc aramayı temizler. Çember kapanınca sorgu sıfırlanır. Etkin sorgu varken merkeze tıklamak alanı tekrar açar. Çember/grup adını düzenlerken de Ctrl+A kullanılabilir.

### 5. Sayfalar arasında gezin

Çemberde tekerleği kaydırarak veya arama etkin değilken merkeze tıklayarak sayfa değiştirin. Klavyeyle sonuçlar arasında ilerlemek gerektiğinde sonraki sayfayı gösterir.

### 6. Panelden dosya açın

Ayırıcının altındaki çember adına tıklayın. Üst alanda yazmak listeyi filtreler. Liste açıldığında ve sorgu değiştiğinde ilk sonuç seçilidir; aşağı ok sonraki sonuca geçer. Tek tıklama seçer; Enter veya çift tıklama açar. Tab alanla liste arasında geçer; Esc pencereyi kapatır. Liste tek kaydırma çubuğu kullanır. Gruplar ve Geri satırı da Enter veya çift tıklamayla açılır.

### 7. Paneli yerleştirin

Panelin boş alanlarından sol tuşla tutup sürükleyin. Panel, monitörün çalışma alanının dört kenarı veya köşeleri boyunca kalır; ortaya bırakılamaz. Konumu kaydedilir. Sağ üstteki ok paneli tek adımda küçültür veya genişletir. Küçük panelin alttaki Çemberler düğmesi tüm çemberlere ulaşır.

### 8. Çemberleri hizalayın

Çemberi merkezinden veya boş alanından sol tuşla sürükleyin; orta tuş da kullanılabilir. Izgara menüsünden Kapalı, 2×2, 3×3, 4×4, 6×6 veya 8×8 seçin. Seçim mevcut konumları değiştirmez; sonraki bırakma konumunu hizalar. Şimdi hizala, Son öğeler dahil çemberleri kendi monitörlerinde uygun boş hücrelere yerleştirir. Yer yoksa ilgili çember yerinde kalır. Yeni kurulumda 4×4 seçilidir.

### 9. Kilidi kullanın

Sol üstteki kilit, çemberlerin hover ile açılmasını ve merkezdeki göster/gizle düğmesini durdurur. Panelden dosya arama ve sürükleme kullanılabilir. Engellenen düğmede beklemek veya ona basmak açıklama gösterir.

### 10. Ayarlar ve yardım

Merkez düğmenin altındaki dişli Ayarlar'ı, grid simgesi ızgarayı, bilgi simgesi kılavuzu açar. Dil / Language seçimi hemen uygulanıp kaydedilir; dosya ve çember/grup adları çevrilmez. Kılavuz tek pencereyle sınırlıdır; tekrar basmak açık pencereyi öne getirir.

### 11. Kullanım ipuçları

İpuçları normal kontrolleri teal, kilit nedeniyle engellenenleri kırmızı, boş taşınabilir alanları mavi çerçeveyle açıklar. Ayarlar → Kullanım ipuçları ile hepsini birlikte açıp kapatabilirsiniz. Panelin sağ tık menüsündeki üçüncü seçenek de aynı ayarı değiştirir; tik işareti ipuçlarının açık olduğunu gösterir.

### 12. Sağ tık ve sistem tepsisi

Panelin sağ tık menüsündeki Çemberler bölümünden de dosya açabilirsiniz. Büyük listeler 32'şer öğelik Devamı alt menülerine ayrılır. Harf tuşları dosyayı başlatmadan seçer; Enter açar. Dosyalar varsayılan uygulamasında, klasörler Explorer'da açılır. Sistem tepsisinden DeskTuk'u gösterin veya Windows ile başlat seçeneğini açın. Masaüstü simgelerini göster, Windows'un kendi simgelerini bağımsız olarak yönetir.

## English

### 1. Use your circles

Hover over a circle to reveal its contents. Click a file icon to open it. Circles store path references; they do not move the original files. Drop files or shortcuts from Explorer onto a circle to add them.

### 2. Organize and move

Use the context menu to create and manage circles or groups. Dragging a file to another circle changes its DeskTuk reference. Right-click a file for its Windows shell menu; file actions chosen there apply to the actual file.

### 3. Search a circle

Type over an open circle; one character is enough. Names starting with your query come first, followed by names containing it. Existing order is preserved within each match group. The first item is highlighted even before typing. Up/Down changes selection; Enter opens the highlighted item. Hovering a file gives its pointer highlight priority.

### 4. Edit your query

Typing opens a native text field. Use Ctrl+A, Ctrl+C/X/V/Z, Shift+arrows, Home/End and mouse selection. Backspace deletes; Escape clears. Closing the circle resets the query. Clicking the centre while a query is active reopens the editor. Circle/group rename supports Ctrl+A too.

### 5. Browse pages

Scroll the wheel, or click the centre when no search is active, to change circle pages. Keyboard navigation reveals the next page when needed.

### 6. Launch from the panel

Click a circle name below the divider. Type in the top field to filter its list. The first result is selected on opening and whenever the query changes; Down advances to the next result. Single-click selects; Enter or double-click opens. Tab switches between field and list; Escape closes the window. Results use one scrollbar. Enter or double-click also navigates groups and Back.

### 7. Place the panel

Drag any blank panel area with the left button. The panel stays on one of the work area's four edges or corners; it cannot remain in the middle. Its position is saved. The top-right arrow collapses or expands it immediately. The Circles button below the compact panel gives access to all circles.

### 8. Align circles

Drag a circle by its centre or empty background with the left button; the middle button also works. Choose Off, 2×2, 3×3, 4×4, 6×6 or 8×8 from Grid. Choosing a grid keeps existing positions and snaps future drag releases. Align now places circles, including Recent, into suitable free cells on their own monitors. A circle stays in place if no suitable cell is available. New installations start at 4×4.

### 9. Use the lock

The top-left lock stops circles opening on hover and disables the centre show/hide tile. Panel file search and dragging remain available. Hovering or clicking a disabled control shows an explanation.

### 10. Settings and help

Below the centre tile, the gear opens Settings, the grid icon opens grid choices and the info icon opens the guide. Language selection applies immediately and is saved; filenames and circle/group names are not translated. The guide opens once; another click brings its existing window forward.

### 11. Usage tips

Tips explain ordinary controls with a teal border, locked controls with red and blank draggable areas with blue. Settings → Usage tips turns all of them on or off together. The third entry in the panel's right-click menu changes the same setting; a checkmark means tips are enabled.

### 12. Context menu and tray

The panel's context menu also offers Circles for launching files. Large lists use More submenus of 32 entries. Letter keys select without launching; Enter opens. Files use their default app; folders open in Explorer. Use the tray icon to show DeskTuk or opt into Windows startup. Show desktop icons controls Windows' own icons independently.
